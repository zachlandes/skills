Open only the image files listed above.
Do not look for, open or ask about code, other files or anything else.

Assume nothing on screen has earned its place yet.
Go through it element by element - every effect, colour, container, border, label, icon, divider, decoration, control and line of text - and ask whether the person using this screen would lose anything if it were gone, or if it were swapped for the plainest standard equivalent: a native control, plain text, a solid colour, no container at all.

List every element that fails that test, the one with the most impact first, each with:

- what it is and where, precisely enough for someone else to find it;
- what it costs the person using the screen - attention, space, clarity, speed - or why it adds nothing;
- whether to cut it outright or replace it, and with what.

Restraint reads as quality, so when in doubt, list it.
Do not suggest additions, and say nothing about the elements you would keep.
